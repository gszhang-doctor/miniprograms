# 施工经营管理微信小程序

面向施工现场项目负责人、工头和站内管理人员的轻量化经营管理工具。项目将项目、混凝土车次、付款、欠账、分红和数据汇总集中在一个微信小程序中，减少纸笔和聊天记录带来的重复录入、费用统计偏差与信息遗漏。

当前版本为可运行 MVP，使用微信小程序原生框架和微信云开发实现本地记录、云端同步及数据导出。

## 项目背景

施工现场通常需要反复登记项目名称、工头、司机、车牌、施工部位、方数和单价，并持续跟踪付款、欠账和分红状态。原有方式存在以下问题：

- 车次信息分散在纸张、聊天记录或多个表格中，难以按项目汇总。
- 混凝土费用和泵车费用容易遗漏，付款进度口径不一致。
- 司机、车牌、施工部位等高频字段重复输入，录入效率低。
- 欠账和分红缺少结清状态、负责人和创建者信息，后续追踪成本高。
- 多设备使用时，本地数据与云端数据容易出现不同步或覆盖问题。

## 产品经理职责

本项目由个人完成产品设计、原型实现和功能开发，主要负责：

1. 通过临床实习和施工业务接触理解一线用户的沟通习惯、记录方式和操作痛点。
2. 梳理用户场景和需求池，定义项目、车次、付款、欠账、分红等核心业务对象及数据关系。
3. 输出 PRD、交互流程、字段说明、版本迭代记录和测试验收清单。
4. 拆解费用计算、自动编号、结清状态、预设项复用、创建者追踪等业务规则。
5. 设计三 Tab 信息架构、空状态引导、长按编辑删除、二次确认、电话拨号和数据导出等交互。
6. 根据反馈进行版本优先级排序，使用真实业务数据验证统计口径和异常场景。
7. 使用 AI Coding 工具协助实现页面和云函数，并负责方案审核、代码修正、联调和验收。

## 核心迭代

### V1：核心业务闭环

- 建立项目、车次、付款、欠账和分红的完整记录流程。
- 支持项目详情、车次列表、付款列表、欠账列表和数据汇总。
- 统一车次金额计算：`混凝土费用 = 方数 × 单价`，`总金额 = 混凝土费用 + 泵车费用`。

### V2：现场录入效率优化

- 车次编号改为按项目累计生成，例如已有 `001` 时自动生成 `002`。
- 增加司机、车牌、施工部位、单价、方数、泵车司机和泵车费用预设项。
- 支持自定义输入、历史值复用、两个随机泵车司机测试按钮。
- 预设项支持长按进入抖动删除模式，并将新增/删除结果持久化。

### V3：经营数据与协作能力

- 项目按创建日期和时间倒序排列，最新项目优先展示。
- 项目和车次支持编辑；项目删除需经过两次确认。
- 欠账记录增加日期、姓名、电话、金额、结清期限、站内负责人和拨号入口。
- 汇总中增加泵车司机、泵车费用和最后一次车次司机。
- 支持本地数据、微信云数据库和云函数分页拉取，使用更新时间进行智能合并。
- 支持一键导出 Excel 和 CSV，便于电脑端复盘和归档。

## AI 协作方式

项目采用“产品经理定义问题，AI 辅助实现，人工验证闭环”的方式：

- 使用腾讯 CodeBuddy / AI Coding 辅助生成页面骨架、事件处理、云函数和样式代码。
- 使用 OpenAI Codex 辅助需求拆解、字段设计、代码重构、异常排查、语法检查和 README 编写。
- 先提供业务背景、页面结构和验收标准，再让 AI 输出实现建议；对涉及金额、删除、同步和权限的代码逐项人工复核。
- 通过 `node --check`、JSON 解析检查、`git diff --check` 和微信开发者工具进行分层验证。
- AI 生成的代码不直接视为最终方案，由产品负责人根据实际业务规则进行取舍、修改和验收。

## 技术实现

- **客户端**：微信小程序原生框架、WXML、WXSS、JavaScript
- **数据层**：微信本地存储 + 微信云数据库
- **云函数**：`getAllData`（分页获取数据）、`exportExcel`（生成 Excel）
- **同步策略**：自动上传、手动刷新同步、按业务 ID 和 `updateTime` 智能合并
- **导出格式**：Excel 工作簿、UTF-8 CSV
- **核心数据集合**：`projects`、`trucks`、`payments`、`debts`、`bonusRecords`、`userInfo`、`presetConfig`

## 运行步骤

### 1. 环境准备

- 安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。
- 准备已开通云开发的小程序 AppID 和云开发环境。
- 克隆仓库并进入项目目录：

```bash
git clone https://github.com/gszhang-doctor/miniprograms.git
cd miniprograms
```

### 2. 导入小程序

1. 打开微信开发者工具，选择“导入项目”。
2. 项目目录选择仓库根目录，开发模式选择“小程序”。
3. 检查 `project.config.json` 中的 `appid` 是否属于当前账号。
4. 在 `miniprogram/app.js` 中确认 `wx.cloud.init` 的 `env` 为自己的云开发环境 ID。

### 3. 配置云数据库

在云开发控制台创建以下集合：

```text
projects
trucks
payments
debts
bonusRecords
userInfo
foremanPhoneMap
presetConfig
```

权限规则和字段示例见 [`database.config.md`](./database.config.md)。个人测试可使用较宽权限，正式环境应根据 `openid` 和创建者设置最小权限。

### 4. 部署云函数

在微信开发者工具中分别打开并部署：

- `cloudfunctions/getAllData`
- `cloudfunctions/exportExcel`

部署 `exportExcel` 前安装依赖：

```bash
cd cloudfunctions/exportExcel
npm install
```

部署 `getAllData` 前安装依赖：

```bash
cd ../getAllData
npm install
```

### 5. 编译与验证

回到小程序根目录后重新编译，依次验证：

- 创建项目并登记车次，确认车次编号和金额计算。
- 创建付款、欠账和分红记录，确认创建者与云同步。
- 编辑/删除项目和车次，确认二次确认及关联数据处理。
- 在首页测试 Excel / CSV 导出。
